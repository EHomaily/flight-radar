# ✈️ رادار أسعار التذاكر

يراقب أسعار الطيران يومياً من مطار أو عدة مطارات تختارها، إلى وجهة محددة أو **أي وجهة**، وينبّهك على **تيليجرام** عندما:

- 🚨 ينزل السعر **تحت حدّك** الذي تحدده.
- 🔥 يظهر سعر **أقل من المعتاد** (أقل بـ 15٪ أو أكثر من متوسط آخر 30 يوماً).
- 🏷️ تظهر **عروض أسعار غير معتادة** على مساراتك (Aviasales).
- 📰 تعلن شركات الطيران (ناس، أديل، السعودية…) عن **تخفيضات** في الأخبار.

وكل تنبيه يحمل **روابط مقارنة** تفتح نفس الرحلة مباشرة في Trip.com و Skyscanner و Kayak (وتضيف أي تطبيق آخر كالمسافر بقالب رابط)، مع **السعر التقديري بعد خصوماتك** (أكواد التطبيقات وعروض البطاقات البنكية).

ويعرض لك في **لوحة ويب** (تفتح من الآيفون): تقويم **أرخص يوم في الشهر**، منحنى السعر اليومي، أرخص الوجهات، وروابط مباشرة لـ Google Flights و Aviasales.

يعمل مجاناً على **GitHub Actions** — جهازك لا يلزم أن يكون شغالاً.

## من أين تأتي الأسعار؟

| المصدر | ماذا يقدم | ملاحظة |
|---|---|---|
| **Aviasales Data API** (Travelpayouts) | أسعار كل أيام الشهر، البحث لأي وجهة، العروض الخاصة | مجاني. البيانات من بحث المستخدمين خلال ~48 ساعة، لذا هي "مؤشر" |
| **Google Flights** (مكتبة fast-flights) | تحقق حي من أرخص التواريخ | بدون مفتاح. السعر المؤكد يظهر بعلامة ✅ |
| **أخبار Google** | إعلانات تخفيضات شركات الطيران | تعمل حتى مع مواقع الطيران التي تمنع القراءة الآلية |

> **لماذا ليس Amadeus؟** أغلقت Amadeus واجهاتها المجانية (Self-Service) في 17 يوليو 2026، ولم يبقَ إلا عقود Enterprise المدفوعة.

## الإعداد (مرة واحدة — حوالي 15 دقيقة)

### 1) أنشئ المستودع على GitHub
1. أنشئ مستودعاً جديداً باسم `flight-radar`. اجعله **Public** إن أردت لوحة الويب مجاناً (المستودع لا يحتوي أي أسرار — الرموز تُحفظ في Secrets).
2. ارفع كل محتويات هذا المجلد إليه (بما فيها مجلد `.github`).

### 2) رمز Travelpayouts (مجاني)
1. سجّل في [travelpayouts.com](https://www.travelpayouts.com) كشريك.
2. انضم لبرنامج **Aviasales** من قائمة البرامج.
3. انسخ الرمز من: Profile ← **API token**.

### 3) بوت تيليجرام
1. في تيليجرام افتح **@BotFather** وأرسل `/newbot` واتبع الخطوات ← انسخ **الرمز** (Token).
2. افتح البوت الجديد وأرسل له أي رسالة (مثل: مرحبا).
3. افتح في المتصفح: `https://api.telegram.org/bot<الرمز>/getUpdates`
   وابحث عن `"chat":{"id":123456789` ← هذا الرقم هو **Chat ID**.

### 4) أضف الأسرار في GitHub
المستودع ← **Settings ← Secrets and variables ← Actions ← New repository secret**:

| الاسم | القيمة |
|---|---|
| `TRAVELPAYOUTS_TOKEN` | رمز Travelpayouts |
| `TELEGRAM_BOT_TOKEN` | رمز البوت |
| `TELEGRAM_CHAT_ID` | رقم المحادثة |

### 5) فعّل لوحة الويب (اختياري لكن أنصح به)
1. **Settings ← Pages ← Source:** اختر **GitHub Actions**.
2. **Settings ← Secrets and variables ← Actions ← تبويب Variables ← New variable:**
   الاسم `ENABLE_PAGES` والقيمة `true`.
3. رابط اللوحة سيكون: `https://<اسم-حسابك>.github.io/flight-radar/` — أضفه للشاشة الرئيسية في الآيفون (Safari ← مشاركة ← Add to Home Screen).

### 6) شغّله أول مرة
**Actions ← Flight Radar ← Run workflow**. خلال 2–3 دقائق يصلك الملخص على تيليجرام.
بعدها يعمل تلقائياً كل يوم الساعة **6:14 صباحاً** بتوقيت الرياض.

## الاستخدام اليومي

### إضافة أو تعديل مراقبة
عدّل `config.yaml` من GitHub مباشرة (القلم ✏️، يعمل من تطبيق GitHub على الآيفون). أمثلة:

```yaml
watches:
  # مسار محدد، ذهاب وعودة، من 4 إلى 10 أيام
  - name: الرياض ← إسطنبول (ديسمبر)
    origins: [RUH]
    destinations: [IST, SAW]
    months: [2026-12]
    trip: round-trip
    stay_days: [4, 10]
    max_price: 1400

  # عدة مطارات ← أي وجهة
  - name: إجازة قصيرة لأي مكان
    origins: [RUH, JED, DMM]
    destinations: [ANY]
    months: [2027-01]
    trip: round-trip
    stay_days: [3, 5]
    max_price: 900
    exclude: [BAH, DXB]   # وجهات لا تريدها

  # فترة تواريخ محددة بدل أشهر كاملة، مباشر فقط
  - name: جازان ← الرياض (العيد)
    origins: [GIZ]
    destinations: [RUH]
    dates: {from: 2027-03-15, to: 2027-03-25}
    trip: one-way
    direct_only: true
    max_price: 300
```

بعد الحفظ، يظهر ✅ أو ❌ بجانب التعديل في GitHub (فحص تلقائي للإعدادات). إن ظهر ❌ افتحه لترى سبب الخطأ بالعربي.

### مقارنة التطبيقات (المسافر، Trip.com، …)
الأسعار الحصرية داخل التطبيقات لا تظهر في أي واجهة عامة، لذلك الرادار يختصر عليك الطريق بدل أن يقرأها:
- **روابط مقارنة:** كل تنبيه فيه 🔁 روابط تفتح نفس الرحلة والتاريخ في كل موقع. على الآيفون يفتح الرابط داخل التطبيق إن كان مثبتاً ويدعم ذلك.
- **إضافة المسافر أو Wego أو أي تطبيق:** ابحث عن رحلة في موقعهم من المتصفح، انسخ الرابط من شريط العنوان، وأضفه في `compare_sites` بعد استبدال الرموز والتواريخ بالمتغيرات (الشرح داخل `config.yaml`). مثال لشكل القالب:
  ```yaml
  - name: المسافر
    one_way: "https://www.almosafer.com/...{FROM}-{TO}/{depart}..."
  ```
- **خصوماتك:** أضف في `discounts` أي كود أو عرض بطاقة تعرفه (النسبة، الحد الأقصى، تاريخ الانتهاء). يظهر 💳 السعر التقديري بعده في كل تنبيه، وإن وضعت `use_for_alerts: true` يُحسب في مقارنة حدّك.
- **رصد عروض التطبيقات:** يبحث يومياً في الأخبار عن عروض وأكواد المسافر و Trip.com و Wego وعروض البطاقات البنكية، ويراقب صفحة أكواد Trip.com.

### بحث سريع لمرة واحدة
**Actions ← بحث سريع ← Run workflow** ← أدخل المطار والوجهة (أو `ANY`) والشهر ← النتيجة تصلك على تيليجرام.
(أو من زر **🔎 بحث سريع** أعلى لوحة الويب.)

### ما الذي يصلك على تيليجرام؟
- **ملخص يومي:** أفضل سعر لكل مراقبة، التغيّر عن أمس 🔻🔺، وأرخص يوم في كل شهر.
- **تنبيه فوري** عند النزول تحت حدّك أو ظهور سعر أقل من المعتاد — لا يتكرر نفس التنبيه قبل 3 أيام إلا إذا نزل السعر أكثر.
- **العروض والتخفيضات** الجديدة فقط.

لإيقاف الملخص اليومي والاكتفاء بالتنبيهات: `daily_digest: false` في `config.yaml`.

## ملاحظات مهمة
- **تأكد دائماً من السعر قبل الحجز.** أسعار Aviasales من ذاكرة بحث حديثة وقد تتغير؛ الأسعار المؤكدة حياً من Google Flights تظهر بعلامة ✅.
- Google قد يرفض بعض الطلبات أحياناً من خوادم GitHub؛ عندها يبقى سعر Aviasales هو المعروض ولا يتوقف الرادار.
- إن قلّت الأسعار لمسار ما، جرّب `market: sa` أو `market: ae` في الإعدادات (سوق البيانات).
- GitHub قد يوقف الجداول المجدولة في المستودعات التي لا نشاط فيها لمدة 60 يوماً. إن توقف الرادار، افتح Actions واضغط **Enable workflow**.
- يُحفظ سجل الأسعار في مجلد `data/` داخل المستودع نفسه.

## للمطورين
```bash
pip install -r requirements.txt pytest
python run.py check-config
python -m pytest -q                       # اختبارات بدون إنترنت (خادم وهمي)
TRAVELPAYOUTS_TOKEN=... python run.py daily --dry-run   # يطبع الرسائل بدل إرسالها
```

```
radar/
  config.py          تحميل الإعدادات والتحقق منها
  travelpayouts.py   عميل Aviasales Data API
  google_flights.py  التحقق الحي عبر Google Flights
  engine.py          جمع الأسعار، تقويم أرخص الأيام، منطق التنبيهات
  deals.py           العروض الخاصة + أخبار التخفيضات + مراقبة الصفحات
  messages.py        صياغة رسائل تيليجرام بالعربية
  runner.py          التشغيل اليومي والبحث السريع
docs/index.html      لوحة الويب
```
